# Mifune Console

The Mifune Console gives you managed AGRO nodes. Mifune operates each node. You open the Console in your browser.

Open the Console at [console.mifune.dev](https://console.mifune.dev).

To run AGRO on your own machine instead, read the [self-host guide](/docs/agro/intro).
